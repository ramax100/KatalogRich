Token BotFather

Gunakan token untuk menambahkan bot baru atau memperbarui token bot yang sudah ada.

Token biasanya diawali angka, lalu tanda titik dua.

Token Anda terlindungi. Token hanya dikirim untuk verifikasi ke API Telegram dan tidak pernah ditampilkan kembali di panel.

Belum punya token?

Dapatkan token dalam beberapa langkah singkat melalui Telegram.

  1. 1

    Buka @BotFather di aplikasi Telegram.

  2. 2

    Kirim perintah /newbot, lalu ikuti instruksi untuk membuat bot.

  3. 3

    Salin HTTP API token yang dikirim oleh BotFather.

  4. 4

    Tempel token tersebut pada form di sebelah kiri.

✦

Tips: Jangan pernah membagikan token bot kepada orang lain. Token memberi akses penuh ke bot Anda.
